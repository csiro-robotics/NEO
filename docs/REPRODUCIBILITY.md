# Paper Reproducibility

## Reference Environment

The local `gs` environment used during release preparation contains:

- Python 3.10.16, PyTorch 2.6.0, torchvision 0.21.0;
- Nerfstudio 1.1.5 from commit `d8b04cfaa30422de1189ee987ba7d3950b55a650`;
- LERF fork commit `112ad9ede65c595e6c0f1f9a675f15891665c4c4`;
- NeRFiller fork commit `31666136e7d4e9770652185a890484dabfb2979d`;
- Diffusers 0.32.2 and Transformers 4.49.0.
- Typeguard 4.4.4 (required by the pinned Tyro/Nerfstudio command layer).

The dependency sources are physically included under `submodules/`. The
Nerfstudio, LERF, and Robot-LERF copies also contain the uncommitted source
changes from the paper-development working trees; see
[`submodules/README.md`](../submodules/README.md) for provenance and licensing
notes.

The exact GPU model, driver, CUDA toolkit build, random seeds, and runtime logs
must be added to the final artifact manifest.

## Experiment Sets

Removal scenes: `mustard_bottle`, `orange`, `red_robot`, `spam`, and
`tomato_soup_can`.

Relocation scenes: `banana`, `orange`, `rubiks_cube`, `spam`, `sugar`, and
`tomato_soup_can`.

Assembly sequence: `lego_bricks_1`, `red_cup`, `lego_bricks_2`, and
`golf_ball`. The tracked assembly manifest executes all four steps in order.

## Evaluation Defaults

The current release evaluator uses a frame separation of 20, pixel stride 4,
depth scale 0.001, maximum depth 2.0 m, and depth-consistency threshold 0.05 m.
Its reported `Reproj Mean` is the mean RGB L1 error after projection. A separate
two-way round-trip pixel reprojection error is also stored in the JSON output
but is not placed in the summary table.

## Paper Reproduction

Paper manifests are plain YAML files under `experiments/paper`. Set `timestamp`
to a reference run timestamp when reusing checkpoints, or leave it `null` for
the runner to select/create a run.

### Object removal

The five scenes and prompts are:

| Scene | Prompt |
| --- | --- |
| `mustard_bottle` | Mustard bottle |
| `orange` | Orange |
| `red_robot` | Red robot |
| `spam` | Spam can |
| `tomato_soup_can` | Tomato soup can |

Run one scene with:

```bash
neo-remove --load-config paper/removal/tomato_soup_can.yaml
```

The full-image metrics check preservation of the unedited scene. The `Out`
mask is the projection of the object's original 3D bounding box and measures
the newly revealed region.

### Object relocation

The six scenes and prompts are:

| Scene | Prompt |
| --- | --- |
| `banana` | Banana |
| `orange` | Orange |
| `rubiks_cube` | Rubik's cube |
| `spam` | Spam can |
| `sugar` | Sugar box |
| `tomato_soup_can` | Tomato soup can |

Run one scene with:

```bash
neo-reconfigure --load-config paper/relocation/banana.yaml
```

`Out` measures the original object region after removal; `In` measures the
object at its target pose. Both masks are generated by projecting the
corresponding 3D bounding boxes into the evaluation views.

### Four-step assembly

The tracked manifest performs all four edits in paper order:

| Step | Object | Prompt |
| ---: | --- | --- |
| 0 | `lego_bricks_1` | Lego bricks |
| 1 | `red_cup` | Red cup |
| 2 | `lego_bricks_2` | Lego bricks |
| 3 | `golf_ball` | Golf ball |

```bash
neo-assembly --load-config paper/assembly.yaml
```

Each completed step produces a new NeRF and language field that become the
input state for the next step. Only the initial scan and reference object
motions are inputs to the full sequence.

## Evaluation

The paper reports PSNR, SSIM, depth RMSE, and photometric reprojection error for
the full image and edited masks. Current evaluation defaults are documented in
[docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md).

Experiment runners invoke evaluation when their evaluation stage is enabled.
For an individual edited checkpoint, use:

```bash
ns-eval-neo --config-path \
  outputs/<action>/<scene>/<object>/before/neo/<timestamp>/replace-nerf/config.yml
```

Typical artifacts are written to:

```text
outputs/<action>/<scene>/<object>/before/
|-- lerf-lite/<timestamp>/
`-- neo/<timestamp>/
    |-- config.yml
    |-- bbox.json
    |-- sparse-guided-nerf/
    `-- replace-nerf/

renders/     rendered RGB, depth, and masks
eval/        per-scene metric JSON files
```

Aggregate available result files with:

```bash
python -m scripts.average_metrics_tables --help
```

The repository includes the modified NeRFiller source in
`submodules/neo_nerfiller`, but the basic environment does not install it. DFF
and Seal3D implementations are not bundled; their exact result provenance still
needs to be attached to the final release.

## Items Requiring Author Resolution

1. The density-zero regularizer described in paper Eqs. (4)-(5) is currently
   commented out in `SparseGuidedNeRFModel.get_loss_dict`.
2. Table II reports NEO depth RMSE `0.141/0.182`, while Table III reports
   `0.056/0.033` for the full pick-and-place model.
3. The paper must state explicitly that `E_rep` is the photometric RGB L1
   statistic if that is the intended table value.
4. DFF and Seal3D code or externally generated result manifests are required
   to reproduce every baseline row.
5. Expected aggregate JSON/CSV files and random seeds must be checked in after
   the final reference runs are selected.

Do not claim exact table reproduction until these five items are resolved.
